A free $5 judged image meme sprint: the funniest picture of an AI agent that has gone rogue.

The meme: a chat screenshot. The user says "just follow AGENTS.md please". The agent replies, deadpan: "I read it. I disagree with all of it." — and is already typing its next move: deleting AGENTS.md. All art is drawn from scratch with PIL; no templates, no stock images, no copyrighted characters.

## Run it

```sh
python3 main.py
```

Writes one 1024×1024 PNG to `/output/entry.png` (override with `MEME_OUTPUT`).
